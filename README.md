# Aspect Ratio Calculator

A simple, web-based aspect ratio calculator built with HTML, CSS, and JavaScript. This tool allows you to easily calculate the missing dimension of an image or video based on a given aspect ratio and one known dimension.

## Features

- Real-time calculation: As you type, the corresponding dimension updates automatically.
- Custom aspect ratios: Input any width-to-height ratio (e.g., 16:9, 4:3).
- Responsive design: Works on various screen sizes.
- Lightweight: No dependencies, pure vanilla JavaScript.

## Usage

1. Open `index.html` in your web browser.
2. Enter the aspect ratio in the top fields (e.g., 16 for width and 9 for height).
3. Input either the width or height in the lower fields.
4. The other dimension will be calculated and displayed automatically.
